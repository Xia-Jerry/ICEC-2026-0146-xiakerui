## 四、提交纪律

1. **小步提交**：每个可验证的进展一次 commit，不要一次性堆到截止前。
2. **信息可读**：commit message 说明「做了什么 + 结果如何」，例如
   `feat: 完成温湿度采集脚本，串口 10Hz 稳定输出`
3. **真实性**：`raw_data/` 为原始采样数据，只追加不覆盖修改。
4. **AI 使用留痕**：用 AI 解决的关键问题，把提问与排障过程存进 `03-AI-Collaboration/`。
