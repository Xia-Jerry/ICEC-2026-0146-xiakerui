## 课题 08：多姿态步态加速度特征采集与对比

### 8.1 实验设计

用 Phyphox「加速度（含 g）」采集四种状态下的三轴加速度时序：**静止站立、平地慢走、快跑、上下楼梯**。手机固定位置全程一致（前胸口袋），采样率与设备信息见采集索引表。

- 控制变量：同一部手机、同一固定位置、同一直线路径、每段前后各留 3 秒静止用于切段。
- 自变量：运动状态。
- 记录时长：静止 30s / 慢走 60s / 快跑 30s / 上下楼梯 60s。

### 8.3 特征提取

用 1 秒滑动窗口（重叠 50%）对合加速度序列计算以下特征：

| 状态 | 均值 (m/s²) | 标准差 | 峰值 | 主频 (Hz) |
|---|---|---|---|---|
| 静止 | ≈9.8 | | | |
| 平地慢走 | | | | |
| 快跑 | | | | |
| 上下楼梯 | | | | |

> 理论预期：静止时几乎只有重力，标准差接近 0；慢走峰值约 10–14 m/s²、步频 1.5–2 Hz；快跑峰值可到 20 m/s² 以上、步频 >2.5 Hz；上下楼梯因重心起伏，会出现幅度大但频率低的周期性波动。
