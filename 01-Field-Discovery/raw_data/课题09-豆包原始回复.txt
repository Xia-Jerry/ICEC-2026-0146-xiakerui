这是 Webots 仿真机器人的 Python 控制器代码：python运行import math
from controller import Robot

TIME_STEP = 32

robot = Robot()
motor = robot.getDevice("motor")
F = 2.0
t = 0.0

while robot.step(TIME_STEP) != -1:
    position = math.sin(t * 2.0 * math.pi * F)
    motor.setPosition(position)
    t += TIME_STEP / 1000
代码说明
TIME_STEP = 32：仿真步长，单位 ms
F=2.0：正弦信号频率 2Hz
math.sin(t * 2.0 * math.pi * F)：生成正弦位置指令，电机做周期性往复摆动
t += TIME_STEP / 1000：把毫秒转为秒，更新时间

作用：控制名为 motor 的关节电机，以 2Hz 的正弦规律来回转动。
