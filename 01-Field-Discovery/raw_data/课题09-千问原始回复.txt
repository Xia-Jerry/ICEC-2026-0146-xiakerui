from controller import Robot, Keyboard

TIME_STEP = 32
robot = Robot()
kb = robot.getKeyboard()
kb.enable(TIME_STEP)

while robot.step(TIME_STEP) != -1:
    keyIn = kb.getKey()
    if keyIn = Keyboard.UP: print("UP")
    if keyIn = Keyboard.DOWN: print("down")
    if keyIn = Keyboard.LEFT: print("left")
    if keyIn = Keyboard.RIGHT: print("right")
3. 代码存在的错误与问题
语法错误（致命错误）： 第 10-13 行的 if 判断条件中使用了赋值符号 =，在 Python 中比较两个值是否相等必须使用双等号 ==。这会导致代码无法运行。
缺少默认按键处理： 代码中缺少对 Keyboard.UP, DOWN, LEFT, RIGHT 之外的按键处理。如果没有按键按下，kb.getKey() 会返回 None（Webots Python API 中），此时与 Keyboard.UP 等常量比较可能会报错或产生非预期结果。通常建议加上 if keyIn == -1: 的处理或者使用 elif 结构。
缺少实际运动逻辑： 目前代码只在控制台打印方向，并没有获取机器人的电机（Motors）并设置目标速度（setVelocity），因此机器人无法真正移动。
左侧仿真环境异常： 左侧的 3D 仿真窗口中只显示了地板和墙壁，没有加载任何机器人模型。这会导致代码在第 4 行 robot = Robot() 之后，尝试获取键盘或电机时因为找不到对应的节点而报错（或者无法产生任何实际效果）。
